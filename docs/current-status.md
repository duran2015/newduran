# Newduran 当前代码状态

## 已形成的能力

### Agent Hub

- Agent、人格、知识、模型服务、工具、MCP 与技能管理
- Agent 有向关系、消息通信、状态查询与协作审计
- 群组、频道、流程、决策与运行记录
- 扩展权限、用量记录与本地运行支持

### 游戏制作

- 游戏项目与六步编辑流程
- 世界状态、行动条件、数值影响与行动试算
- 引用现有 Agent 作为导演或 NPC
- 事件条件、参与人物、路线衔接、回合推进与结局
- 图片、立绘、音乐、音效资源与场景绑定
- 草稿试玩、自然语言行动理解、规则确认与结算
- NPC 现场回应、任务进度、剧情记录、复盘与固定版本发布

- 五个主要场景
- 莫云岑、罗重霄、谢衡等 NPC
- 玩家任务、动态世界状态和多条故事路线
- 监管冻结、董事会罢免等三条结局路径

## 仓库整理原则

- 不提交本地数据库、密钥、登录信息、构建产物或浏览器测试临时文件。
- 游戏素材放在 `assets/`，代码通过资源 ID 引用，不把图片和音频写死在规则中。
- 产品页面使用普通用户能够理解的语言，内部字段只留在代码或开发者信息中。
- 发布版本是不可变快照，后续编辑只修改草稿。

## 已知工程问题

- 后端全量测试中，两项依赖 SQLite 并发写入的消息测试可能出现 `database table is locked`。游戏主链、编辑器与结局验收不依赖这两项测试，但在正式 CI 收口前仍需改为稳定的事务/重试策略或隔离测试数据库。
