1. 新建或选择测试游戏，设置一项数值、一条行动规则、绑定导演和 NPC。
2. 设置行动后触发的事件，关联另一个场景；设置一个结束事件。
3. 草稿试玩输入行动的自然语言表达：先看提案，确认后才改变数值。

5. 确认有效行动，检查真实人物回应、事件场景、音乐及音效；浏览器可能要求先点击启用声音。
6. 到达结束条件，检查结局、停止输入、过程回顾及每次数值变化。
7. 发布版本后修改草稿，确认旧发布版本不跟随修改；重新开局不覆盖旧局。
